🚀 Project full-stack-app
A full-stack web application designed to integrate front-end and back-end operations, fully compatible with modern cloud-based environments.
Objectives:
To build a web application with end-to-end functionality, encompassing both front-end user interfaces and back-end management systems.
To study and apply modern software development processes.
To deploy the application on a cloud platform (such as Vercel), making it accessible for real-world use by end users.

✨ Features
🔐 User Authentication: Secure sign-up, login, and profile management.

📱 Responsive Design: Fully optimized for mobile, tablet, and desktop screens.

⚡ High Performance: Fast loading times and smooth user experience.

🛡️ Data Validation: Robust ID verification and input sanitization (using Mongoose/Regex).


🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript / React 

Backend: Node.js, Express.js

Database: MongoDB, Mongoose

Styling: Tailwind CSS 

API Testing : Postman
